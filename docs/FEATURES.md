# Mission 功能边界

这是当前已实现功能的维护清单，依据 `6383020` 的代码和既有产品决定整理。新增、删除功能或改变业务角色需由所有者或指定维护者确认；普通修复在既定范围内直接完成。开发方式见 [AGENTS.md](../AGENTS.md)。

## 产品与账号

- 可见品牌「結 YUI」，面向学生团队的任务协作和荣誉成长；目前一个共享团队空间，不是多租户 SaaS。
- 正式环境采用独立身份服务 OIDC/PKCE、应用授权和本域会话。账号停用、密码恢复、邀请码、应用授权归身份门户；Mission 不设置管理员。
- 本地演示仍可使用独立账号和数据；不能将演示身份带入正式站，不能因配置缺失把正式站退回本地密码登录。
- Mission 的任务、讨论、勋章、作品独立存储；只复用身份接入，不接管 GPU 调度、节点、训练或其他业务平台的数据。

## 任务协作

- 小任务发布、筛选、认领、提交成果、验收/退回、讨论；内容包括标题、说明、标签、项目、投入分量、紧急程度、截止时间和交付要求。
- 大任务多人加入/退出、人数上限、发布者也可参与、拆出分工；成员提交，发布者验收并选择获奖成员。分工沿用小任务流程，大任务发布者可验收分工，但不能验收自己接的分工。
- 发布时可以指定小任务接手人或大任务成员，不能指定自己；大任务发布者通过「我也一起做」参与，不超过人数上限。
- 进行中的执行人可申请延期，验收人审批或拒绝；验收人可直接延后待认领或进行中任务。同一任务只保留一个待回复申请，提交或直接延期等动作会关闭旧申请；不能自己审批自己的申请。
- 大任务延期不自动修改各份分工的截止时间；延期不改变勋章、经验和已确定的冷门加成。截止后禁止新认领/加入，已参与者仍可提交；符合条件的任务延期后可重新招人。
- 时间按 UTC 保存、查看者时区显示；保留操作和成果历史。

## 发现与团队

- 按标签、项目、投入、关键词和可解锁勋章筛选；任务墙、大任务列表、我的任务及待处理提醒。
- 根据主动选择的方向和过往经历分别推荐，可换一批或标记不感兴趣。
- 登录成员共同维护团队标签表，包括说明、排序、改名、合并和移除；保留现有任务记录。
- 团队动态、鼓掌、名牌墙，展示实际贡献。

## 荣誉与休闲

- 点/线/面与紧急程度组成六类勋章；验收后发放经验，冷门任务有既定加成；同一任务的同一成员不重复发奖。
- 收藏柜、颁奖、称号、名牌、团队收集进度、学期回顾及本地图片导出。
- 縁側：3D 积木创作与展示、一笔画入门/每日/随机关卡、盖章挑战。已解锁内容可重复玩；游戏不发任务经验和勋章，无付费、兑换或排行榜。
- 动效/音效开关、减少动态支持、移动端和键盘操作；核心任务流程保留普通表单入口。

## 数据与维护

- Flask/Jinja 单体、SQLite、独立本地启动和生产 WSGI 入口；生产使用反向代理 HTTPS。
- 备份恢复与必要的数据升级；已有任务、用户 ID、讨论、勋章和作品保留。
- 定期清理过期辅助记录：未完成或可归并的小游戏记录、过期推荐忽略标记。任务（包括过期任务）、讨论、勋章、称号和作品不在清理范围内。

## 当前不包含

- 真实悬赏支付、资金托管、转账、积分兑换、付费游戏内容。
- 多团队租户、复杂审批、通用工作流引擎、微服务拆分。
- 附件上传、邮件/短信通知、完整任务编辑/取消/转派、任务删除与回收站。
- Mission 自己的账号管理后台、密码找回体系、GPU 管理或训练接口。
- 自动生产部署：当前 CI 只测试、构建和导出镜像；接通部署另行实施。

这份清单描述现状，不把计划写成已经完成的功能，也不作为顺手实现缺失功能的授权。
